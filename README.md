# Prussian Shopping Cart

## Overview

Prussian Shopping Cart is a full-stack e-commerce application built to strengthen my understanding of front-end and back-end development. The project focuses on how products are managed throughout the shopping journey, from browsing products and managing a cart to completing a secure checkout process.

A key goal of the project was learning how to store, retrieve, and manage cart data while integrating a payment gateway using Stripe.

## Objectives

* Learn how shopping cart functionality works in a real-world e-commerce application.
* Understand how front-end and back-end systems communicate.
* Implement cart management and checkout workflows.
* Integrate Stripe for secure online payments.
* Gain experience working with product data and order processing.

## Features

* Product browsing interface
* Add products to cart
* Update cart quantities
* Remove products from cart
* Cart state management
* Checkout workflow
* Stripe payment integration
* Responsive user interface

## Technologies Used

### Front-End

* React
* JavaScript
* HTML
* CSS

### Back-End

* Node.js
* Express.js

### Payments

* Stripe API

## What I Learned

Through this project I gained practical experience in:

* Managing shopping cart state and user interactions.
* Building communication between the front-end and back-end.
* Processing checkout requests.
* Integrating third-party APIs such as Stripe.
* Structuring e-commerce workflows from product selection through payment.
* Debugging and deploying web applications.

## Project Outcome

This project helped me develop a deeper understanding of full-stack web development and e-commerce systems by combining front-end user experiences with back-end business logic and payment processing.
